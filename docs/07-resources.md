# 6. Resources and where to go next

## From this project

- `static/` — the HTML site. Open any `.html` file in your browser.
- `worksheets/` — printable timesheet, earnings, and shift-swap worksheets.
- `tools/` — local helper scripts with tests.
- `docs/` — this manual (markdown).

## Free starting points

- A free chatbot (for example at chat.openai.com or claude.ai) — for drafting
  messages and brainstorming.
- Ollama (ollama.com) — for running AI locally on your computer.
- Google Sheets or LibreOffice Calc — free spreadsheets for earnings tracking.
